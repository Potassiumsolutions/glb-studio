    3 · Scene & camera

    Keeps every clip the same size & framing so they line up. Turn off to auto-fit each clip on its own.
    Travel: each segment continues where the last left off. Stay in place: the character is pinned to one spot — loop a walk/run to keep it in place. Both remove the snap-back on the final frame.
    AI-generated walk/run/fall clips animate in place. In Travel mode this makes them actually move — walks/runs go forward (auto-estimated from the stride, along the way the character faces), and falls descend. Set 0 to keep them on the spot. Clips that already travel (jumps, sprints, real climbs) are unaffected.
    Off = one character at a time (sequence). On = every character plays together, side by side; each loops its own moves. Drag a character in the preview to move it.
    Preview controls (like CAD):
    • Drag — move the character on the ground
    • Right-drag (or Shift+drag) — spin the character
    • Hold Space / Alt (or middle-mouse) + drag — orbit the camera; +right-drag pans up/down
    • Mouse wheel — zoom in / out
