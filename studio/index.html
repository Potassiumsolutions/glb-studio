◆ KSOL Designs GLB Studio — how it works

Rig → Animate → Stitch, with one shared library
✕ Close

KSOL Designs GLB Studio bundles three tools into one pipeline. Whatever one tool makes lands in a shared Studio Library, so the next tool can use it instantly — no exporting files or running scripts between steps.

1 🧍 Rig — turn a model into a base character

Open Rig and drop a textured .glb character. Pick its skeleton type — Biped, Quad, or Bird — then fit the joints onto the model (choose a view, drag the joints; turn on Mirror L/R to rig one side and mirror it). Click Bind & preview weights to check the skinning, then ⬇ Export rigged GLB.

The export downloads the GLB and adds the character to the Studio Library automatically.

2 🐾 Animate — build motions for quadrupeds & birds

Open Animate, choose the rig type, pick an animation (Walk, Trot, Gallop, Wing flap…), and tune its speed, amplitude and loop length. When it looks right, click ➕ Add current animation → Studio Library. The motion joins the Stitcher's retarget list, tagged to its skeleton.

3 🎬 Stitch — assemble the video

Open Stitch. The ◆ Studio Library card lists your rigged characters — click Load to drop one in as a base character. Its skeleton's motions (the built-in 579 for bipeds, plus anything you made in Animate) appear in the Motion library (retarget) panel below — click a motion to add it as a clip. Then set the scene, camera, audio and cross-fades, and Render the MP4.

◆ The shared library

Click the ◆ Library pill any time to see everything the tools have shared — rigged models (base characters) and baked motions (retarget clips) — and delete anything you don't need.

Tip: everything runs locally in your browser. Each tool also opens on its own, but the shared library only works inside GLB Studio (it's tied to this one address). Run it locally with run-local.bat (or any static server), or open your hosted link.
